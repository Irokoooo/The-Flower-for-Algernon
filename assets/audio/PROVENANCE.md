# Original generated prototype audio

`room-tone-prototype.wav`, `paper-soft-prototype.wav`, and `chime-soft-prototype.wav`
are original procedural prototype outputs created for this project using the adjacent
`generate-prototypes.mjs`. They contain only mathematical waveforms and seeded noise;
no recording, external sample, voice model, or third-party audio was used.

License identifier: `LicenseRef-ALGERNON-Original-Prototype`.
These outputs are supplied for use, modification, and distribution within the ALGERNON
project. This is project provenance, not a claim that an external stock license or
public-domain dedication exists. Attribution record: “Original procedural audio for ALGERNON”.

Regenerate from the project root: `node assets/audio/generate-prototypes.mjs`.
Output is mono 16-bit PCM, 22050 Hz. Room tone is a four-second periodic loop;
paper and chime are one-shots. All are prototypes pending human listening approval.
No production voice recordings are included.
